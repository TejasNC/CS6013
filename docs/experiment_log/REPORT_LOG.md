## 1. Method summary

Per linear layer W (out × in): rotate the input dimension with a random-sign, random-permutation block-Hadamard (exactly invertible), choose a per-row uniform step so the entropy of the integer codes matches a target bit rate, quantize with GPTQ error feedback using the layer-input Hessian (collected on HMMT teacher traces), entropy-code the codes with rANS. Restore decodes, dequantizes, un-rotates and writes bf16. The tied embedding (and lm_head) uses three tiers: T1 high-rate scalar quantization, T2 low-rate scalar quantization, T3 nearest of 1024 centroid rows; tier membership is a 2-bit map. MTP head is dropped (restored as zeros). Optional LoRA adapters (int8, per-row fp16 scales, counted in the size) are merged at restore: W = dequant(Q) + scale·B·A.
